# Contributing

Small, focused improvements are welcome. Open an issue before redesigning Mila or changing the package format.

## Useful contributions

- Clearer installation instructions backed by an actual platform test.
- Animation corrections that preserve Mila's identity and pixel-art style.
- Better previews, accessibility descriptions, or troubleshooting notes.

## Before submitting

1. Describe the problem and your proposed change.
2. Keep `pet.json` and the atlas compatible with the documented format.
3. For visual changes, include before/after previews and inspect all affected loops and directional boundaries.
4. Test in Codex when possible; record the app version and operating system, or explicitly state that runtime testing was not performed.
5. Update documentation and the unreleased changelog when behavior or assets change.
6. Exclude private conversations, credentials, reference photos without permission, generation scratch files, and local agent configuration.

Use descriptive commit messages such as `docs(install) clarify custom Codex home paths` or `fix(sprites) correct waving frame alignment`.

Discuss the work respectfully and make feedback specific and actionable. Contributions and reuse remain subject to the licensing status in [LICENSING.md](LICENSING.md).
